# calendar-frontend

하이엔드 미니프로젝트팀 HyTodo의 프론트엔드 저장소입니다.

## Tech Stack

- React
- JavaScript
- Vite
- React Router
- Axios
- CSS

## Getting Started

```powershell
npm install
npm run dev
```

The dev server runs at:

```text
http://127.0.0.1:5173/
```

## Environment Variables

Create `.env` from `.env.example`:

```env
VITE_API_BASE_URL=http://localhost:8080
```

## Scripts

```powershell
npm run dev
npm run build
npm run lint
npm run preview
```
